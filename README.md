## 📖 About

**CropIQ** is a comprehensive, user-friendly web platform that bridges technology and agriculture. It connects farmers to markets, delivers real-time weather insights, offers essential farming resources, and fosters collaboration — all in one place.

Our mission is to enhance productivity, sustainability, and profitability for farmers worldwide by making technology accessible to everyone in the farming community.

## ✨ Features

| Feature | Description |
|---|---|
| 🌦️ **Weather Report** | Real-time and accurate weather updates to help plan farming activities and avoid crop loss |
| 🛒 **Marketplace** | Connect with buyers and sellers to trade crops, seeds, and farming equipment |
| 🏛️ **Government Schemes** | Access the latest government schemes and subsidies for sustainable agriculture |

## 🏃 Getting Started

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/manavendr09/Mini-Project-CropIQ-.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd Mini-Project-CropIQ-
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   open index.html
   ```
   Or use a local server like VS Code's **Live Server** extension for the best experience.

## 🌐 Deployment

This project is deployed on **Vercel**. Any push to the `main` branch automatically triggers a new deployment.

To deploy your own copy:

1. Fork this repository
2. Go to [vercel.com](https://vercel.com) and import your fork
3. Set **Framework Preset** to `Other`, leave build settings blank
4. Click **Deploy** 🚀
